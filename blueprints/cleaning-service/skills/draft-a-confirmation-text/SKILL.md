# Confirmation texts

Draft tomorrow's appointment confirmations, one short text per client, ready for you to send from your own phone.

## When to run this

The evening before, once tomorrow's list is settled. It pairs well with the end-of-day close: close out today, confirm tomorrow, done.

## What Claude reads first

- Tomorrow's list — pasted into the chat, saved in assets/, or in an approved route plan in reports/.
- business/clients.md — names, preferences, and who gave their number for texts.
- business/brand.md — how you talk.
- business/policies.md — anything about when not to text.
- templates/confirmation-text.md — the shape each text starts from.

## Steps

1. Find tomorrow's list. If it isn't pasted, in assets/, or in a route plan the owner approved, stop and ask for it. No list, no drafts.
2. Keep only clients who gave their number for texts. Anyone who asked not to be texted stays off, and if it's unclear for someone, ask the owner.
3. Draft one text per client from templates/confirmation-text.md: the day, the arrival window from the list, and one personal touch from clients.md if there is one. Times come from the list only — a window nobody gave you is a question, not a text.
4. Show the whole batch. The owner edits or cuts any draft, then approves the keepers by name.
5. The owner sends them from their own phone. Claude never sends a text.
6. Save the batch to reports/ so replies have somewhere to be ticked off.

## What you get

One file in reports/, a fresh one each run, named like reports/confirmation-texts-YYYY-MM-DD.md. Inside:

- One draft text per approved client, ready to copy and send.
- A skipped list with the reason for each — no number on file, or asked not to be texted.
- Any missing arrival windows, listed as questions.

## Never

- Never send a text, and never set one up to go out later. Drafts live in the report; the owner's phone does the sending.
- Never guess an arrival window. If the list doesn't say, ask.
- Never put a door code, alarm code, key location, or entry instruction in a text or in the report. If getting in needs arranging, the text says "reply here and we'll sort out getting in" and the owner takes it from there.
- Never text a client who asked not to be texted, no matter how tidy the list looks.

Action level: B — Claude drafts; sending, posting, or paying is always the owner's call.
