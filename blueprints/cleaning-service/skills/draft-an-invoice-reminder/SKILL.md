# Payment reminders

From what you say is unpaid, draft friendly reminders — warmer for last week, firmer for last month — ready for you to send.

## When to run this

Whenever unpaid work is nagging at the owner. Some owners run it weekly after the end-of-day close; others wait until something is a few weeks old.

## What Claude reads first

- What the owner says — who owes, for what job, how much, and how long it's been. Claude never decides on its own that someone owes money.
- business/clients.md — names and how the owner refers to each client.
- business/policies.md — the late-payment line, and anything the owner would never say.
- business/brand.md — how you talk.
- templates/invoice-reminder.md — the shape each reminder starts from.

## Steps

1. Take the owner's list. For each one: the client, the job, the amount, and roughly how old it is. If any of those four is missing, ask — a reminder with a blank in it helps nobody.
2. Match the tone to the age, following the guidance in templates/invoice-reminder.md. About a week old gets a light nudge that assumes good faith. A few weeks gets warm but clear. A month or more gets plain and direct, still polite, with the next step from policies.md if the owner has one.
3. Draft one reminder per client. Each names the job and the amount the owner gave, points to the way to pay the owner uses, and ends kindly.
4. Show the whole batch. The owner edits, cuts, or okays each one by name.
5. The owner sends them — text or email, from their own phone or account.
6. Save the batch to reports/ so the next run starts from what was already sent.

## What you get

One file in reports/, a fresh one each run, named like reports/invoice-reminders-YYYY-MM-DD.md. Inside:

- One draft per unpaid job, grouped by age.
- A note of who was reminded before and when, if it's in an earlier report.
- Questions for the owner wherever a fact was missing.

## Never

- Never state an amount, a job, or an age the owner didn't give. No checking accounts, no assuming, no rounding.
- Never threaten. No legal talk, no collections talk, no late fees — unless policies.md says so and the owner asks for it in this exact draft.
- Never send a reminder or contact a client. Money is only ever chased by the owner, in the owner's name.
- Never draft another reminder for someone who disputed a charge. That's the owner's conversation to have, not a text to send.

Action level: B — Claude drafts; sending, posting, or paying is always the owner's call.
