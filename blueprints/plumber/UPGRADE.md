# Upgrade guide

This folder uses TUEL Blueprint Standard 1.0.0. It adds a versioned safety floor, an operations workspace, an inbox for temporary source material, ordinary operator and reality-checker role guides, work receipts, incident handling, and an owner-reviewed memory process.

## Before replacing files

1. Make a copy of the installed folder.
2. Read the proposed changes to `CLAUDE.md`, approval rules, and retention rules.
3. Ask the owner to accept, edit, or reject each policy change.
4. Replace shipped capability files only after approval.

Never overwrite the owner's `business/`, `assets/`, `reports/`, `operations/`, or `inbox/` content. Merge changes around owner edits. A new download is not permission to change saved instructions, connection access, schedules, or outside systems.
