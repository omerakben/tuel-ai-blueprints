# Draft an estimate follow-up

Estimates you sent and never heard back on get one polite nudge each — drafted for you, sent by you.

## When to run this

- A few estimates went quiet and you want to give them a nudge.
- The weekly estimate chase flagged open estimates and you're ready to act.
- Next week looks thin and the quiet estimates are the easiest work to win.

## What Claude reads first

- reports/ — the estimates saved there, plus any notes on replies or nudges already made.
- business/clients.md — how each customer likes to be reached, and any "don't contact" notes.
- business/policies.md — how long your estimates stay good.
- business/brand.md — how you talk, so every note sounds like you.
- templates/follow-up-note.md — the shape each nudge starts from.

## Steps

1. Name the estimates to chase, or ask "which are still open?" and Claude lists what it can see in reports/ — who, what job, when it went out. Anything you sent outside this folder, just tell Claude about it.
2. Claude checks each one: has a nudge already been drafted or sent for it? One estimate gets one nudge. Anything already nudged goes on a "your call" list instead — you decide whether a second touch is worth it, and say so fresh.
3. You confirm the list. Cross off anyone — a customer you'd rather ring personally, a job you no longer want.
4. Claude drafts one short, friendly note per estimate: a reminder the estimate exists, the job in a few words, and an easy way to say "still thinking" or "no thanks". No pressure lines, no fake deadlines.
5. The numbers stay exactly as sent. If you want to change the price, that's a new estimate, not a nudge.
6. Claude shows you the whole batch. You edit or cut any note, approve the keepers by name, and send them yourself.
7. Claude saves the run to reports/ and marks each estimate as nudged, so next time nobody gets chased twice.

## What you get

One file in reports/, a fresh one each run, named like reports/estimate-follow-ups-YYYY-MM-DD.md. Inside:

- The open-estimate list: customer, job, when the estimate went out.
- One approved nudge per estimate, ready to copy and send.
- The "your call" list — estimates already nudged once, waiting on your decision.

## Never

- Never more than one nudge per estimate unless you ask for it fresh, by name.
- Never invent urgency — nothing about prices going up or the calendar filling unless it's true and you said it.
- Never change the estimate's numbers inside a nudge.
- Never chase a customer marked "don't contact" in clients.md, or anyone who already said no.
- Never send a note itself — every nudge leaves from your phone or account.

Action level: B — Claude drafts; sending, posting, or paying is always the owner's call.
