# End of day

Closes out the day with you step by step, then shows you tomorrow at a glance.

Mode: runs on your computer — Claude Desktop and this folder need to be open.

Drafts only — nothing goes out on a timer. <!-- action level: B -->

## How to turn it on

In Claude Desktop, create a scheduled task for around the time you usually get back and paste the prompt below as the task's instructions, exactly as written.

You can skip the schedule too. Any evening, open this folder and say the prompt once the van is parked. It works the same.

## The prompt

```text
It's the end of the day. Read the business/ folder first — it is the source of truth for the business.

Then:

1. Walk me through the close, one question at a time: which jobs got done today, what I collected on each (I will give you the numbers), what got invoiced but is still unpaid, what rolled over to tomorrow, and any estimate I promised someone. Do not fill in anything I have not given you.
2. When we finish, save the report as reports/end-of-day-[today's date].md. If anything money-related came up that needs a professional eye, add a short "for the bookkeeper" list at the bottom.
3. Preview tomorrow in 3 lines from the latest week plan in reports/: the first stop, plus any parts or prep worth flagging. If there is no plan for tomorrow, say so and ask me.

Use only what is in business/, reports/, or what I tell you tonight. If a fact is missing, ask. Never invent numbers.

End by listing anything that needs my decision, one per line. If nothing does, say so.
```
