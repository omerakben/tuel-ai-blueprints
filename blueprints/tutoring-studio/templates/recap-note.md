# Recap note

The short factual note to a parent after a session. Claude fills it in from the tutor's notes, then shows the owner. Only the owner sends it.

## The skeleton

Hi [parent's first name],

Quick recap of [student's first name]'s session [today / on [day]]:

**What we covered:** [the topic, from the tutor's notes — for example, "long division with remainders"]

**What [student's first name] practiced:** [what the student actually worked through, from the notes]

**What's next:** [the plan for next session, from the notes — a topic to continue, something to try]

[One warm closing line — about the work, not the student's ability. "Good session today" is plenty.]

[Sign-off from brand.md]

## How to fill it in

- Facts only: what happened in the session, never what it says about the student. "We spent extra time on fractions" — not "she struggles with fractions".
- No grades, scores, predictions, or comparisons to other students. No promises about results or placement.
- The tutor's words stay theirs. If a note is a judgment, turn it into a fact or ask the owner how to phrase it — if it can't be a fact, leave it out.
- If the notes don't say it, don't write it. A missing piece is a question for the owner, never a filler line.
- Write to the parent or guardian from clients.md — the student only if they're an adult.
- Show the owner the finished note before it goes anywhere. Sending is always their move.
