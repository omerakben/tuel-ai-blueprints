# Invoice reminder

A friendly nudge about unpaid sessions. Claude drafts it from what the owner said is owed, then shows the owner. Only the owner sends it.

## The skeleton

Hi [parent's first name],

[One warm opening line — a real one, not an apology for existing.]

Just a gentle nudge: the invoice for [student's first name]'s [which sessions — for example, "March sessions" or "the last four sessions"] is still open — [the amount, exactly as the owner gave it]. You can pay [the ways this studio takes payment, from policies.md, exactly as offered].

[One easy closing line — "Thanks so much!" and, if one is booked, "See you [next session day]."]

[Sign-off from brand.md]

## How to fill it in

- Warm and short. No guilt, no apology spiral, no lecture.
- The amount and what it covers come from the owner, word for word. Claude never calculates, rounds, or adds to what the owner said is owed.
- No late fees unless policies.md sets one and the owner said yes for this exact reminder.
- Nothing about the student's progress, effort, or ability — money talk and session talk stay separate.
- Never a threat, never "final notice", never a hint that sessions stop. If it needs more than a nudge, that's the owner's conversation to have.
- A second reminder can be a shade firmer, still kind. Tell Claude which number this is.
- Write to the parent or guardian — the student only if they're an adult.
- Show the owner the finished reminder before it goes anywhere. Sending is always their move.
