# Opening note

A short, personal text to a family who asked for more sessions, when a spot opens up. Claude drafts it and shows the owner. Only the owner sends it.

## The skeleton

Hi [parent's first name]! A [day and time] spot just opened up [with [tutor's name] / for [subject]]. You'd mentioned wanting more sessions for [student's first name] — want it? First to reply gets it. [An easy out, like "If you'd rather not hear about openings, just say so and I'll stop."]

## How to fill it in

- Two or three sentences, no more. It is a text, not a letter.
- It should read like the owner typed it between sessions. If it sounds like a company wrote it, redo it.
- Only draft this for families whose notes in clients.md say they asked for more sessions. Not sure they did? Ask the owner first.
- Address it to the parent or guardian — the student only if they're an adult.
- The opening comes from the owner, never from a guess about the calendar.
- Every note offers the time as "first to reply" — never promised to more than one family quietly.
- Keep the easy out in. Every note carries a simple way to say stop.
- Show the owner the exact text before it is sent. They send it, or say send it — a past yes does not cover this one.
