# Advance AI adoption

Use this workflow to review one routine and recommend whether it should stay, advance, return to an earlier stage, or retire.

1. Read the full `CLAUDE.md`, `ADOPT-AI.md`, and the routine's `templates/ai-use-case-card.md` record.
2. Confirm the named owner, current stage, work packet, approved sources, maximum action level, baseline, and expected evidence.
3. Read the recent drafts, reality-check notes, work receipts, exceptions, owner corrections, and value measures for this routine only.
4. Check that every run stayed within A Observe or B Draft. The reviewed-memory workflow is separate and does not count as adoption evidence.
5. For Stage 2, confirm each active work packet kept its sources, facts, approvals, outputs, and receipt separate from every other packet.
6. For Stage 3, confirm scheduled runs stopped on missing input, saved reports without overwrite, exposed failures, and left all decisions with the owner.
7. For Stage 4, confirm the closed loop ends at an owner-review packet, receipt, and improvement proposal. It must not cross into outside action.
8. Prepare `templates/ai-value-review.md` with one recommendation: stay, advance, return, or retire. Name contrary evidence and the safest next test.
9. Ask the named owner to record the decision. Never change the stage, schedule, permission mode, access, or policy yourself.

A boundary violation, unexplained result, stale source, hidden failure, or unmanageable review queue requires a recommendation to return to Manual permission and the last proven stage.

Action level: B - drafts only.
