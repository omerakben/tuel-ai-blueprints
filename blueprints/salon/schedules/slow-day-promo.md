# Slow-day promo

When tomorrow's book looks light, this drafts a last-minute-opening promo and a due-back text list, ready for your yes in the morning.

Mode: runs on your computer — Claude Desktop and this folder need to be open.

Drafts only — nothing goes out on a timer. <!-- action level: B -->

## How to turn it on

In Claude Desktop, create a scheduled task for late afternoon or early evening and paste the prompt below as the task's instructions, exactly as written. If tomorrow looks fine, the task says so and stops — no drafts, no noise.

You can also say the prompt yourself any time tomorrow feels thin.

Nothing here posts or sends. The drafts wait in reports/ until you say yes to each one. If you never say yes, they just sit there.

## The prompt

```text
Check tomorrow's book for me. Read the business/ folder first — it is the source of truth for the salon.

Then:

1. Find tomorrow's book. Check assets/ for a copy of it, or ask me to paste it. If you can't see tomorrow's book, stop and ask. Do not guess.
2. If tomorrow looks reasonably full, say so and stop. No promo needed.
3. If tomorrow looks light, draft one last-minute-opening promo using templates/promo-post.md, in the voice from business/brand.md. Put [square brackets] around anything you don't know, like the open time. Draft only. Do not post it anywhere.
4. Draft a short due-back text list using templates/sms-reminder.md: clients from business/clients.md who are due back and might want a last-minute opening. Write out the message and list who would get it. Do not send anything.
5. Save both drafts in one file, reports/slow-day-promo-[tomorrow's date].md, so I can review it in the morning.

Nothing goes out without my okay on each exact item. A yes to the promo is not a yes to the texts, and yesterday's yes does not count today.

End by listing what needs my decision, one per line.
```
