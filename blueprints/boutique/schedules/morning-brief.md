# Morning brief

A short rundown of your day before you flip the sign, saved where you can find it again.

Mode: runs on your computer — Claude Desktop and this folder need to be open.

Drafts only — nothing goes out on a timer. <!-- action level: B -->

## How to turn it on

In Claude Desktop, create a scheduled task and pick a time before you open — half an hour before the door works well. Paste the prompt below as the task's instructions, exactly as written.

You don't need the schedule, though. Any morning, open this folder and say the prompt yourself. Same brief either way.

The brief works from what's already here: yesterday's close, recent hold replies, and what you've told Claude about deliveries. The more you mention the evening before, the sharper the morning reads.

## The prompt

```text
Time for the morning brief. Read the business/ folder first — it is the source of truth for the shop.

Then:

1. Read yesterday's end-of-day report in reports/, if there is one, plus any hold replies from the last few days.
2. Write a brief of 6 to 8 lines covering: anything left open from yesterday's close, holds a customer may pick up today, deliveries I've mentioned or that are noted in business/suppliers.md — never guessed, what's worth putting front and center today, and one small suggestion for the day.
3. If you're missing something you need — like whether a delivery landed — ask me instead of guessing.
4. Save it as reports/morning-brief-[today's date].md.

Use only what is in business/, assets/, recent reports, or what I tell you. If a fact is not there, ask me. Never invent stock, prices, or names.

End by listing anything that needs my decision, one per line. If nothing does, say so.
```
